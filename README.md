# Smart Water Tank Control System

A simple embedded system using ESP32 and a float switch to automatically control a water pump based on tank water level.

## Features
- Automatic pump control
- Float switch water level sensing
- Relay-based pump switching
- Serial monitoring for debugging

## Hardware Used
- ESP32 WROOM 32
- Vertical Float Switch
- Relay Module
- 6V DC Water Pump
- 4xAA Battery Pack

## Working
- Low water level -> Pump ON
- High water level -> Pump OFF
